## Adaptation

This CommonKit fork keeps the useful writing controls and removes the
pejorative score name. It names the broad mode `technical`, makes factual
fidelity the first constraint, expands exclusions, and treats the heuristic
only as evaluation evidence. It does not claim ASD-STE100 certification.
